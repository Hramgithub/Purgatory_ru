# История кандидата — значки подсказок и фазы Луны (21 октября 2026)

Найдена ошибка маршрутизации материала в `RepairFormSubMeshes`: у спрайтового
TMP-фрагмента также может быть заполнен `fontAsset`, поэтому прежняя проверка
русского шрифта заменяла материал значка материалом букв. Теперь фрагменты
с `spriteAsset` исключаются **до** любой замены шрифтового материала. Штатный
атлас значков, UV, tint и экземпляры материалов маскирования не меняются.
Добавлена скрытая Unity-проба для всех семи именованных спрайтов сценария:
health, willpower, blank, rage, harano, circle, circle-filled. Проба воспроизводит
условие старой ошибки и проверяет сохранение материалов/текстуры в смеси
с кириллицей, жирным и курсивом. Если нативный атлас ещё не загружен сценой,
проверка откладывается, а не выдаётся за пройденную.

В `PlayerState.InitStats` найдены восемь фаз. Добавлен отдельный чистый
обработчик конечного TMP-текста: новолуние, растущий серп, первая четверть,
растущая выпуклая Луна, полнолуние, убывающая выпуклая Луна, последняя четверть,
убывающий серп. Он обрабатывает в том числе `<b>Фаза Луны:</b> first quarter.`.
Значения статистики, getMoonphase/setMoonphase, команды, сохранения и основной
сценарий не изменяются. Произвольная проза с упоминанием Луны не заменяется.

Пройдены 89 Python-тестов, 267 C#-проверок (включая 56 случаев восьми фаз),
а настоящий Ink runtime из установленной игры отдельно вычислил все восемь
подсказок фаз и четыре подсказки характеристик с исходными sprite-тегами.
Сборка Release — ноль ошибок/предупреждений; проверка личных путей/символов
в DLL пройдена. SHA-256 кандидата:
`38b3aa148118ae1334f0e3d2057a43122092bbd0bf9d6b410d576dda2ddf2332`.
Сводка — `localization/sprites-moon-review.json`.

По указанию пользователя клиент не перезапускался, установленная DLL не
заменялась. Unity-проба и визуальный QA именно этого кандидата ещё не пройдены.
Сборка включает и подготовленный ниже общий проход по подписям. Старый ZIP
v0.1.6 и его хеш-гейты/свидетельства не переписаны; нового релиза пока нет.
