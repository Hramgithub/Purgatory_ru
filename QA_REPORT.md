# Проверка beta v0.1.2 — 19 октября 2026

Перевод 63 частей объединён в основной сценарий игры: 14 067 строк, пропусков нет.
Проверены структура JSON, плейсхолдеры, названия навыков и личные имена,
разделители команд интерфейса и служебные метки форматирования.
Основной сценарий успешно загружается `Ink.Runtime.Story` из установленной игры.

При проверке на Windows исправлены:

- загрузка кириллического шрифта через системный TrueType-файл;
- переведённые метки `HEADER:`, `INFO:` и `STYLE TUTORIAL:`;
- кавычки в параметрах команд создания персонажа;
- ложная защита имён внутри слов `Pattern`, `Patron`, `January`, `Path`;
- кодировка установщика для Windows PowerShell 5.1.

После сообщения о лишних «В в окне Харано исправлена проверка продолжений
команд. Встроенные значки больше не обрывают распознавание параметров.
Все восемь команд создания персонажа выполнены через реальный Ink runtime
с тестовыми внешними функциями. У каждой проверены семь полей, совпадение
размеров списков вариантов и неизменность идентификаторов/флагов/изображения.
Старый сценарий v0.1.1 проваливает этот тест на `introduction.harano.0.2`
(пять полей вместо семи); исправленный проходит все восемь команд.
Полный отчёт включён в пакет как `UI-COMMAND-QA.json` и привязан к SHA-256
сценария. Без актуального успешного отчёта упаковка завершается ошибкой.

Повторная сборка по публикуемому индексу без локального английского каталога
дала побайтно идентичный сценарий.

Установка и удаление проверены на тестовой папке через Windows PowerShell 5.1.
Пакет установлен в настоящую Steam-версию игры. Журнал подтвердил:

```text
Loading [Purgatory Russian Localization 0.1.2]
Loaded Russian Ink story (19 972 447 characters).
Installed dynamic Cyrillic TextMeshPro fallback font.
Replaced the main Purgatory Ink story with the Russian localization.
```

Визуально проверены вступление, русский текст, заголовок, выделения, блок
обучения и окно выбора физических навыков. Названия `Athletics`, `Stealth`,
`Survival` сохранены; описание `Athletics` отображается по-русски.
В v0.1.2 окно Харано проверено после загрузки существующего сохранения:
видны два предусмотренных исходной командой варианта с правильными значками,
а нижняя подпись полностью показывает «В бой! +» и значок Ярости.
Выбор низкого Харано успешно продолжил сюжет и сохранил прогресс.
Это начальная проверка работоспособности, а не полное прохождение
всех сюжетных веток. Машинному переводу ещё может требоваться литературная правка.

Главное меню, заставки глав и статические элементы HUD остаются на английском.
Личные имена и названия навыков/Даров сохраняются в оригинальном написании.
